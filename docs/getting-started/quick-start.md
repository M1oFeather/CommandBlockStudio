# 快速上手

## 打开工作台

1. 进入创造模式或取得命令方块编辑权限。
2. 放置并打开命令方块，或打开命令方块矿车。
3. 原版编辑界面会替换为 Command Block Studio。

默认首先打开编辑器视图。顶部显示方块上下文和工作区页签，左侧活动栏用于切换编辑器、快速文档、问题、输出、工具和可选注释。

## 输入第一条命令

在编辑器中输入：

```mcfunction
say Hello from Command Block Studio
```

补全列表会读取当前世界或服务器的命令树。选择候选后按 ++tab++ 或 ++enter++ 接受；普通输入状态下，++enter++ 不会保存或关闭窗口。

## 保存方式

自动保存默认开启：

- 输入停止约 350 毫秒后静默保存。
- 关闭界面或切换工作区页签前再次保存。
- 不在聊天栏发送重复的保存成功消息。

底部只保留“保存”和“取消”：“保存”会提交修改并关闭界面，++ctrl+s++ 会保存但保持编辑器打开。关闭自动保存后，若仍有修改，按 ++esc++ 或切换页签时会弹出确认窗口；此提醒可在设置中关闭。

## 查看提示与问题

- 将鼠标停在命令、参数或候选上，查看对应解释与示例。
- 按 ++ctrl+space++ 主动打开当前位置补全。
- 按 ++ctrl+shift+space++ 插入当前命令模板。
- 点击错误状态栏右侧的小按钮，跳转到精确错误行列。
- 左侧活动栏使用问号、感叹号和显示器图标分别打开快速文档、问题和上次输出。

## 使用工作区页签

当前方块始终位于页签区域。检测到连锁命令方块时，它们会作为连锁页签排列在旁边。每个页签右侧的小图钉只控制对应命令方块的固定状态；将鼠标放在页签条上滚动可横向浏览，不会自动切换页签。

固定页签最多保存 16 个位置，并在切换世界后清空。更多行为见[工作区与连锁页签](../guide/workspace.md)。
