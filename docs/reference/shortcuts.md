# 快捷键

## 编辑器

| 快捷键 | 功能 |
| --- | --- |
| ++ctrl+space++ | 主动打开当前位置补全 |
| ++enter++ / ++tab++ | 接受选中的补全候选 |
| ++ctrl+shift+space++ | 插入当前根命令模板 |
| ++ctrl+f++ / ++ctrl+h++ | 打开查找 / 替换输入框 |
| ++f3++ / ++shift+f3++ | 下一个 / 上一个搜索匹配项 |
| ++tab++ | 没有补全窗口时填入缺失参数或跳到下一个占位符 |
| ++shift+tab++ | 跳到上一个模板占位符 |
| ++ctrl+s++ | 保存修改并保持 Studio 打开 |
| ++ctrl+z++ | 撤销 |
| ++ctrl+y++ / ++ctrl+shift+z++ | 重做 |
| ++up++ / ++down++ | 在补全候选之间移动 |
| ++home++ / ++end++ | 当前可视行首 / 行尾 |
| ++ctrl+home++ / ++ctrl+end++ | 整条命令开头 / 末尾 |
| ++esc++ | 先关闭补全；再次按下时按保存配置退出 |

普通输入状态下，++enter++ 不会自动保存并关闭窗口。

## 聊天命令助手

| 快捷键 | 功能 |
| --- | --- |
| ++ctrl+space++ | 聊天内容以 `/` 开头时主动打开增强补全 |
| ++up++ / ++down++ | 在聊天命令候选之间移动 |
| ++tab++ | 接受当前聊天命令候选 |
| ++esc++ | 先关闭候选列表，再关闭聊天框 |

鼠标位于右侧命令助手内时，滚轮只滚动助手文档，不会同时滚动聊天记录。

## 世界工作模式

| 快捷键 | 功能 |
| --- | --- |
| ++f3+f4++ | 切换 Command Block Studio 工作模式 |

工作模式开启后，准星指向命令方块会在方块表面前方显示朝向玩家的全息命令投影。Studio 会接管原版的 ++f3+f4++ 游戏模式切换快捷键；再次按下可关闭工作模式。

## 区域选择

默认按 ++semicolon++ 记录区域角点：

1. 第一次按下记录第一个角点。
2. 第二次按下记录第二个角点。
3. 生成 `x`、`y`、`z`、`dx`、`dy`、`dz` 形式的区域参数并写入剪贴板。

按键可以在 Minecraft 控制设置中重新绑定。

## 鼠标

| 操作 | 功能 |
| --- | --- |
| 悬停命令或参数 | 显示对应说明和示例 |
| 悬停补全候选 | 显示候选语义、图标或预览 |
| 点击行号 | 将光标定位到对应可视行 |
| 点击错误栏跳转按钮 | 定位到当前 Brigadier 错误 |
| 拖动编辑器滚动条 | 只滚动视口，不改变文本选区 |
| 滚轮 | 按设置的步长滚动编辑器或文档 |
