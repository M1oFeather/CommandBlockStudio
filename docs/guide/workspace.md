# 工作区与连锁页签

## 页签类型

工作区位于编辑器上方，避免连锁方块图标与左侧活动栏或底部状态栏重叠。

| 类型 | 来源 | 颜色与用途 |
| --- | --- | --- |
| 当前方块 | 玩家刚刚打开的命令方块 | 绿色表示单独方块，青色表示连锁方块 |
| 组合页签 | 六个方向上彼此相邻的命令方块 | 一个页签内用连续方块图标表示，点击图标切换成员；含连锁成员时使用青色色条 |
| 连锁页签 | 未合并到组合中的连锁关系入口 | 青色色条，快速检查对应命令链 |
| 入口页签 | 从世界中唤起本次 Studio 的方块或相邻组合 | 本次 GUI 会话中始终位于第一位，内部切换页签时不会消失 |
| 固定页签 | 点击页签图钉保存的位置 | 黄色标记，跟在当前页签后并在本次世界会话中长期保留 |

从世界中打开命令方块后，该方块或它所在的相邻组合会成为本次 GUI 会话的入口，并始终排在第一位。在 Studio 内切换到其他页签只会改变当前编辑目标，不会替换入口；关闭 Studio 后再从世界打开另一个命令方块，才会建立新的入口。除入口、当前编辑目标和固定项外，先前浏览过的未固定页签不会累计。固定列表最多保留 16 个位置。

## 相邻方块组合

六个方块面上直接相邻的脉冲、连锁或循环命令方块会自动合并为一个组合页签。页签中的每个方块图标都是独立入口，图标角标表示组合内顺序；悬停会显示顺序与精确坐标，点击只切换到该方块，不会改变方块模式或执行关系。

- 含连锁方块时，能够由方块朝向连接出的成员优先按命令执行路径排列。
- 没有连锁关系时，竖直组合按从上到下排列；水平组合按主要延伸方向的坐标递增排列。
- 分支或未进入执行路径的相邻方块会继续使用稳定空间顺序补在组合中，不会从工作区丢失。
- 单个组合页签最多显示 6 个方块，超出后按相同顺序拆成后续组合页签。
- 组合右侧的图钉作用于整组；整组已经固定时，再次点击会取消整组固定。
- 切换当前方块的脉冲、连锁、循环或条件模式时，组合中的当前图标会立即更新；服务端确认后重新扫描组合关系。

## 固定方块

每个页签右侧都有独立的小图钉。普通页签的图钉只改变对应命令方块的固定状态，组合页签的图钉则固定或取消固定整组，操作图钉都不会切换当前编辑目标。取消固定的普通非当前页签会立即离开工作区；入口页签无论是否固定都会保留在第一位，直到关闭 Studio 并从世界打开另一个命令方块。

固定组合在不作为当前组件显示时，只会重新组合仍处于固定状态的成员。这样取消固定的成员不会因为与其他固定方块相邻而重新出现在工作区中。

- 每个世界会话最多固定 16 个方块。
- 超过上限时移除最早固定的位置。
- 切换世界或维度级别对象后，固定列表会清空。
- 固定状态不会写入世界存档，也不会发送给其他玩家。

固定功能适合在调试分散的命令逻辑时保留几个常用入口。如果需要长期说明方块用途，请使用[共享注释](server-features.md)。

## 浏览页签

页签数量超过可用宽度后，可以将鼠标放在页签条上滚动滚轮，横向浏览前后页签。滚轮只移动可见页签窗口，不会自动打开或切换命令方块；点击页签主体后才会切换。右侧的左右箭头提供等价的单步浏览。

## 连锁页签

相邻的连锁命令方块会优先进入组合页签，并按朝向形成的执行路径排列。无法与已知相邻组件合并时，Studio 仍会根据当前方块朝向和链关系生成独立连锁入口。两种入口都只负责导航，不会改变命令方块原有朝向、触发模式或执行顺序。

点击连锁页签前，Studio 会先处理当前未保存内容：

- 自动保存开启：静默保存后切换。
- 自动保存关闭且确认开启：询问是否保存并切换。
- 自动保存关闭且确认关闭：丢弃本地未提交内容后切换。

## 服务端差异

服务端也安装模组时，客户端可以在 64 方块范围内请求刷新目标命令方块数据，再打开对应页签。服务器会验证玩家是否有命令方块编辑权限。

没有服务端模组时，Studio 回退到原版交互路径。距离过远、区块未加载或没有权限的目标可能无法直接切换。
