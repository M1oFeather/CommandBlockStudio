# 编辑器工作台

## 聊天命令助手

打开聊天框并输入 `/` 后，屏幕右侧会自动出现紧凑的 Studio 命令助手。它直接增强原版聊天命令输入，不改变消息历史、命令发送和服务器命令权限。

- 补全候选仍来自当前服务器下发的 Brigadier 命令树。
- `Ctrl+Space` 主动打开补全，方向键选择，`Tab` 接受候选。
- 方块和物品候选显示实际图标；粒子候选显示动态纹理、本地化名称和注册 ID。
- 在线玩家优先排列，并显示头像、延迟和游戏模式；不在线的玩家名使用稳定的原版默认头像。
- 当前命令、参数、候选和语法问题的文档显示在右侧面板中，长内容可在面板内滚动。
- 普通聊天内容不以 `/` 开头时，助手完全隐藏。

聊天命令助手完全在客户端运行，不要求服务器安装 Command Block Studio。可用命令和补全范围仍由服务器同步的命令树决定，因此也能自然识别服务器模组注册的命令。

## 界面分区

### 顶部上下文栏

顶部按钮用于切换命令方块类型、条件模式、红石模式和输出追踪。类型、条件和红石按钮点击后立即同步到服务器，不必先关闭界面。

右侧设置按钮打开 Studio 配置页；更改界面缩放时，设置页和预览会立即重新布局。

底部操作栏的播放按钮用于“运行测试”：先保存当前命令和方块设置，再触发一次目标命令方块。运行测试不会关闭编辑器，也不需要临时放置红石块；远程服务器必须提供对应的 Studio 接口，否则按钮保持禁用并显示原因。

## 命令方块物品提示

使用带方块数据复制功能获得的命令方块物品，会从 `minecraft:block_entity_data` 中读取并显示命令开头。若物品的 `NeoForgeData` 同时带有 Studio 编辑历史，提示还会显示最后编辑时间和编辑者；没有历史时会明确标注物品未携带记录。

命令文本提示完全在客户端解析物品数据。最后编辑信息不会向服务器临时查询，因此只有复制物品本身保存了历史时才会显示。

## 工作模式投影

在世界中按 ++f3+f4++ 切换工作模式。模式开启后，将准星指向命令方块，该方块被指向的表面前方会出现朝向玩家的全息面板，显示命令内容、方块坐标、脉冲/连锁/循环模式、条件/自动状态以及最后编辑信息。

单人世界由集成服务端提供完整数据；多人服务器需要安装支持“命令预览”载荷的 Studio。客户端仍可连接未安装或较旧版本的服务器，但投影会显示接口不可用，而不会尝试读取受保护的命令内容。

### 工作区页签

编辑器上方按当前方块、连锁方块和固定方块组织页签。每个页签右侧都有独立图钉；页签过多时可在页签条上滚动滚轮，或使用左右按钮横向浏览。浏览不会自动切换编辑目标。

### 左侧活动栏

| 图标 | 视图 |
| --- | --- |
| `<>` | 命令编辑器 |
| `?` | 快速文档 |
| `!` | 问题列表 |
| `>_` | 上次输出 |
| `#` | 查找替换、角度和颜色工具 |
| 对话气泡 | 共享注释；紧跟在工具入口后，仅服务端支持时显示 |

### 中央编辑器

编辑器使用多行可视排版，但提交到命令方块的仍是一条原始命令。可视换行、缩进和格式化不会把额外换行写入命令。

行号区域使用颜色表示状态：

- 黄色：光标所在行。
- 红色：包含当前 Brigadier 错误的位置。
- 普通颜色：未选中且无错误的行。

## 参数状态栏

编辑器底部有独立的不透明参数状态区，显示当前参数、可用语法或错误信息。它不占用命令文本的可见行，因此长命令滚到末尾时不会与提示重叠。未写完但仍可继续输入的参数属于“待补全”状态，不会提前标成错误。

例如：

```mcfunction
tp @p 2 71
```

此时会以半透明文字提示缺少 `<z>`。按 ++tab++ 可以填入并选中缺失占位符。

## 编辑辅助

- 自动闭合 `{}`、`[]`、`()` 和引号。
- 选中文字后输入成对符号会包裹选区。
- 光标位于括号两侧时标出对应括号。
- ++ctrl+z++ 撤销，++ctrl+y++ 或 ++ctrl+shift+z++ 重做。
- ++home++ 和 ++end++ 移动到当前可视行首尾。
- ++ctrl+home++ 和 ++ctrl+end++ 移动到整条命令首尾。
- 单击数字参数会选中完整数值，直接输入即可替换；再次单击所选数字或点击数值末尾会收起选区并将光标放到末尾。

## 查找与替换

命令工具默认打开“查找替换”页签。它提供上一个、下一个、区分大小写、替换当前匹配项和全部替换；匹配结果会在编辑器中选中并自动滚动到可见区域。

- ++ctrl+f++：打开工具并聚焦“查找”。
- ++ctrl+h++：打开工具并聚焦“替换为”。
- ++f3++：下一个匹配项。
- ++shift+f3++：上一个匹配项。
- 在查找框按 ++enter++：下一个；按 ++shift+enter++：上一个。

查找替换与角度/颜色转换器使用两个独立页签，较大的 Minecraft GUI 缩放下也不会互相挤压。

## 颜色工具

命令工具中的颜色选择器提供饱和度/亮度二维色盘和独立色相条，并同步显示 RGB、十六进制与十进制颜色值。拖动色盘会实时更新全部输出，也可以直接输入单个 RGB 通道。

## 滚动条

只有内容超出视口时才显示对应滚动条。未悬停时滚动条保持窄尺寸，悬停或拖动时扩大，减少对命令和输出区域的占用。按住滚动条滑块拖动时，事件由滚动条独占，不会同时改变编辑器文本选区。

## 错误定位

语法错误会同时显示：

1. 错误文本片段的红色着色。
2. 错误行号的红色标记。
3. 状态栏中的精确行、列和错误消息。
4. 状态栏右侧的紧凑跳转按钮。

悬停错误只显示有效消息，不重复附加 Minecraft 的“错误见下”提示。
