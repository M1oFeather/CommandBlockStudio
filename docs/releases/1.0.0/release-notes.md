# Command Block Studio 1.0.0

**发布日期：2026-07-19**  
**冻结提交：`6aff965` (`FIX ACTION`)**

Command Block Studio 1.0.0 是项目的首个正式版本，将原版命令方块单行编辑框升级为面向地图作者、命令开发者和服务器维护者的 IDE 风格工作台。

## 主要内容

- Minecraft `1.21.1`、NeoForge `21.1.217`、Java `21`。
- NeoForge 官方 MDK 与原生 API 实现。
- 多行编辑、行号、语法着色、搜索替换、括号配对和撤销重做。
- Brigadier 原生补全、命令模板、参数占位和精确语法诊断。
- 快速文档及中英文命令说明。
- Component 与物品数据组件结构化补全。
- 方块、物品、附魔、玩家头像与粒子候选预览。
- 单独方块、相邻方块、连锁方块和固定方块工作区页签。
- 可选服务端共享注释、最近十次编辑记录与非破坏性回滚。
- 客户端和服务端均可独立安装。

## 安装说明

只需要增强编辑器时，仅安装客户端即可。服务器安装模组后会启用共享注释与编辑记录，但不会要求所有客户端安装。

本模组不依赖 Fabric API、Architectury、Sinytra Connector 或其他加载器兼容层。

## 发布文件

```text
command_block_studio-1.0.0-1.21.1-NeoForge.jar
```

## 后续版本

1.0.0 之后的背包命令摘要、工作模式、聊天命令助手、运行测试和长命令布局修复均属于 `1.1.0`。
