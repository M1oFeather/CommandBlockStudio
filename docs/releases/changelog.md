# 更新日志

这里记录面向玩家的完整中文更新历史。开发者使用的英文日志位于仓库根目录 `CHANGELOG.md`。

## 1.1.0

**状态：待发布**

### 命令方块检查

- 带方块实体数据的命令方块物品会在悬停提示中显示命令开头。
- 物品携带 Studio 编辑历史时，同时显示最后编辑时间和编辑者。
- 新增可自定义工作模式快捷键，默认 `Alt+Tab`。
- 准星指向命令方块时，可在方块前方显示面向玩家的命令全息面板。
- 修复长命令空格宽度、自动换行、鼠标命中与光标位置错位。
- 补全列表、命令用法和快速文档会避让参数状态栏，并在空间不足时翻转到当前行上方。

### 聊天命令助手

- 聊天输入以 `/` 开头时，在右侧四分之一屏幕打开命令助手。
- 复用 Studio 的 Brigadier 补全、快速文档和 `Ctrl+Space` 主动补全。
- 支持方块、物品、粒子和玩家可视化候选。
- 粒子预览支持动画；在线玩家候选可显示头像、延迟与游戏模式。
- 普通聊天不会打开命令助手。

### 运行与兼容

- 新增运行测试按钮，保存草稿后让命令方块执行一次，无需临时红石。
- 命令预览、运行测试等网络能力改为逐载荷协商。
- 客户端和服务端模组版本可以不同。
- 不支持的共享功能会隐藏或禁用，而不是中断连接。
- 继续支持仅客户端或仅服务端安装。

## 1.0.0

**发布日期：2026-07-19**

### NeoForge 原生移植

- 面向 Minecraft `1.21.1` 与 NeoForge `21.1.217` 重建项目。
- 保留 NeoForge 官方 MDK、ModDevGradle、资源模板和运行配置结构。
- 生命周期、按键、配置页面和客户端事件改为 NeoForge 原生 API。
- 不依赖 Fabric API、Architectury、Sinytra Connector 或其他兼容层。

### Studio 编辑器

- 将原版单行界面升级为多行命令工作台。
- 新增行号、语法着色、当前行与错误行标记、搜索替换和精确错误跳转。
- 新增 Brigadier 补全、幽灵文本、参数提示、命令模板和占位符跳转。
- 新增 Component、物品数据组件、方块、物品、附魔、玩家和粒子辅助。
- 新增工作区页签、连锁命令方块分组、独立固定与横向滚动。
- 新增快速文档、问题与输出面板、共享注释和十次编辑历史回滚。
- 新增自动保存、未保存退出确认、响应式缩放与中英文提示。

### 模组命令软兼容

- 为 WorldEdit、Carpet、Create、CMDCam、Corpse、Dynamic Trees、Exposure、Serene Seasons、Supplementaries、WaterFrames、SecurityCraft 和 Yes Steve Model 提供已确认的根命令说明。
- 未内置的服务器命令继续根据当前 Brigadier 命令树生成候选和参数类型说明。
