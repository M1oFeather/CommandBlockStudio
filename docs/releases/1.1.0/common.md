## 一句话简介

把命令方块、聊天指令和现场检查升级为接近 IDE 的 NeoForge 原生命令开发体验。

## 1.1.0 核心更新

- 在带方块实体数据的命令方块物品悬停提示中显示命令开头；存在 Studio 历史时同时显示最后编辑时间和编辑者。
- 新增可自定义的工作模式快捷键，默认 `Alt+Tab`。准星指向命令方块时，在方块前方显示面向玩家的命令全息面板。
- 新增编辑器“运行测试”按钮，保存当前草稿后让命令方块执行一次，无需临时放置红石块。
- 聊天栏输入 `/` 时，在右侧四分之一屏幕打开命令助手，复用 Studio 的补全、文档和可视化候选。
- 聊天助手支持方块、物品、粒子和玩家预览；粒子预览可动画显示，玩家候选可显示头像、延迟和游戏模式。
- 修复超长命令中空格宽度缩小、换行后鼠标命中与光标位置错位的问题。
- 补全列表、参数提示和快速文档会避让状态栏，并在空间不足时翻转到当前行上方。
- 网络能力改为逐功能协商。客户端与服务端版本可以不同，不支持的服务器功能会隐藏或禁用，而不是阻止连接。

## 安装范围

- 仅客户端安装：可使用 Studio 编辑器、聊天命令助手、本地补全、文档、诊断、物品命令摘要和客户端工作模式。
- 仅服务端安装：未安装模组的客户端仍可正常连接并使用原版界面。
- 双端安装：额外启用共享注释、最近十次编辑记录与回滚、运行测试，以及依赖服务器数据的增强预览。
- 客户端与服务端版本不要求完全一致。每项网络功能独立判断接口是否可用。
