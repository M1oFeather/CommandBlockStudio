# 1.1.0 图片清单

## 通用规格

- 封面 `00-cover.png` 使用可辨识的平面命令方块图标、编辑器符号和中英文项目标题组合；尺寸为 `1440x900` PNG（严格 `16:10`），全出血且重要内容位于安全区内。
- 功能截图使用实际游戏画面，不使用界面概念图代替。
- 功能截图建议原始分辨率为 `2560x1440`，发布图导出为 `1600x900` PNG。
- 使用简体中文界面、原版字体和清晰背景；关闭会改变 GUI 或命令显示的资源包。
- 截图中的命令应当可读、合法，并避免出现服务器地址、聊天隐私或玩家 UUID。
- 同一组截图保持一致的 GUI 缩放、世界和命令方块区域。

## 推荐图注

- `01-editor.png`：多行编辑、实时诊断、工作区页签与快速文档集中在同一界面。
- `02-completion.png`：补全来自当前 Brigadier 命令树，复杂参数同时提供结构与说明。
- `03-chat-assistant.png`：普通聊天保持原样，只有 `/` 命令输入会展开命令助手。
- `04-work-mode.png`：不打开 GUI 也能现场检查准星所指命令方块。
- `05-item-tooltip.png`：复制到背包的命令方块可以直接查看命令摘要与编辑信息。
- `06-run-test.png`：保存后执行一次命令方块，无需临时红石。
