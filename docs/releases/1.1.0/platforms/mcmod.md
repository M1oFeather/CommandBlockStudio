## 短介绍

Command Block Studio 是一套面向命令方块作者、地图制作者和服务器维护者的 NeoForge 原生命令开发工作台。它将原版单行编辑框升级为多行编辑器，并把补全、快速文档、语法诊断、工作区页签、现场检查和聊天指令辅助集中到同一套体验中。

## 概述正文

### 像编辑代码一样编辑命令

Command Block Studio 会替换命令方块和命令方块矿车的原版编辑界面。编辑器提供多行排版、行号、语法着色、当前行与错误行标记、搜索替换、括号配对、撤销重做和精确错误跳转。超长命令可以稳定换行和滚动，空格宽度、鼠标命中位置与实际光标保持一致。

补全直接读取当前世界或服务器同步的 Brigadier 命令树，因此原版命令和服务器真实注册的模组命令都可以参与候选生成。命令、参数与候选项会在右侧快速文档中显示说明；文本 Component、物品数据组件、粒子、方块、物品、附魔与玩家候选还可以获得结构化提示或可视化预览。

### 1.1.0：从编辑器走向完整工作流

在聊天栏输入 `/` 后，界面右侧会展开紧凑的命令助手。它复用 Studio 的补全和文档系统，并支持方块、物品、粒子与玩家预览。普通聊天内容不会触发该面板。

工作模式使用可自定义按键，默认是 `Alt+Tab`。开启后，将准星指向命令方块即可在方块前方看到面向玩家的全息命令面板，其中包含结构化换行的命令内容、共享注释、方块模式、坐标和可用的最后编辑信息。创造模式“工具与实用物品”分类还提供基于原版望远镜的命令方块扫描仪，主手或副手持有即可临时启用投影。若系统占用了默认组合键，可以在 Minecraft 的按键绑定页面中修改。

编辑器底部新增运行测试按钮。它会先保存当前草稿，再让对应命令方块执行一次，不再需要为了测试临时放置和拆除红石块。

使用带 NBT/方块实体数据的方式复制命令方块到背包后，物品悬停提示会按 Studio 规则换行显示命令开头。若物品携带共享注释，注释会显示在物品名后的第二行；若携带 Studio 编辑历史，还会显示最后编辑时间与编辑者。

### 工作区与协作

相邻或连锁的命令方块会整理为带顺序图标的工作区页签。每个页签可以独立固定，页签过多时可使用滚轮横向浏览。共享注释页面用于说明命令方块用途；服务器可以为每个命令方块保留最近十次完整编辑记录，并允许像版本管理一样选择旧版本进行非破坏性回滚。

### 客户端与服务端都不是强制依赖

只在客户端安装即可使用编辑器、聊天命令助手、补全、文档、诊断和本地预览，服务器不需要安装本模组。

服务端单独安装也不会要求玩家安装客户端模组。双端同时安装时，共享注释、编辑记录、运行测试等增强功能会按网络接口逐项启用。客户端和服务端版本可以不同；缺少或不兼容的接口只会让对应按钮隐藏或禁用，不会阻止进入服务器。

### 原生 NeoForge

本模组基于 NeoForge 官方 MDK 和原生 API 实现，不依赖 Fabric API、Architectury、Sinytra Connector 或其他加载器兼容层。

## 1.1.0 更新日志

- 新增背包命令方块物品的第二行共享注释、换行命令摘要、最后编辑时间与编辑者提示。
- 新增可自定义工作模式快捷键，默认 `Alt+Tab`，支持带共享注释的命令方块全息投影与手持扫描仪。
- 新增编辑器运行测试按钮。
- 新增聊天栏命令助手和 `Ctrl+Space` 主动补全。
- 新增聊天候选中的方块、物品、粒子与玩家信息预览。
- 修复长命令空格压缩、换行、鼠标命中和光标错位。
- 修复原版补全残留、重复悬停文档、补全点击崩溃、图层遮挡、引号内容选区替换和聊天编辑器初始键盘焦点。
- 修复 Minecraft 1.21.4 与 26.2 中 Studio 图标被放大和裁切的问题。
- 优化补全、参数提示、快速文档与底部状态栏之间的避让。
- 支持客户端与服务端版本不同，并对网络增强功能逐项协商。
