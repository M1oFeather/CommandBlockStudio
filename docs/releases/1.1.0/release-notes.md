# Command Block Studio 1.1.0

**发布日期：2026-07-25**

**版本范围：Git 提交 `6aff965` 之后的新增与修复**

1.1.0 将 Studio 从命令方块编辑器扩展为覆盖背包、聊天输入和世界现场检查的命令开发工作流。

## 新功能

### 背包命令摘要

通过带方块实体数据的方式复制命令方块到背包后，物品悬停提示会按 Studio 规则换行显示命令开头。若物品携带共享注释，注释会显示在物品名后的第二行；Studio 历史还会提供最后编辑时间和编辑者。

### 工作模式

新增可自定义的工作模式快捷键，默认 `Alt+Tab`。开启后，准星指向命令方块时，会在方块前方显示始终面向玩家的全息面板，包括：

- 命令内容；
- 命令方块模式；
- 方块坐标；
- 可用的最后编辑信息。

投影命令使用与 Studio 编辑器一致的结构化换行；若命令方块有共享注释，注释会紧跟投影标题显示。准星保持在同一个方块上时，首次命中的表面会作为固定锚点，避免靠近方块棱角时来回跳动。创造模式“工具与实用物品”分类新增命令方块扫描仪，主手或副手持有即可临时启用投影；它基于带数据标记的原版望远镜，不会破坏客户端与服务端可选安装。

如果操作系统占用 `Alt+Tab`，可在“控制 → 按键绑定 → Command Block Studio”中改绑。

### 聊天命令助手

聊天栏输入 `/` 时，左下角会展开 Studio 多行命令编辑器，右侧四分之一屏幕继续显示命令助手：

- 使用与命令方块编辑器一致的结构化换行、行号和语法着色；
- 使用服务器同步的 Brigadier 命令树；
- 支持 `Ctrl+Space` 主动补全；
- `Enter` 发送命令，`Shift+Enter` 插入手动换行；
- 显示命令、参数和候选文档；
- 支持方块、物品、粒子与玩家预览；
- 普通聊天保持原样。

编辑器会在打开后立即取得键盘焦点；补全列表只在 Studio 编辑区内显示，右侧文档可见时不再叠加重复悬停框。

### 运行测试

编辑器新增运行测试按钮。按钮会先保存当前草稿，再让目标命令方块执行一次，无需放置红石块。

## 修复与优化

- 修复长命令中空格被压缩的问题。
- 修复自动换行后鼠标命中、文本选择和光标位置错位。
- 单击引号内文本时会选中引号内的完整内容，第二次单击会把光标移到内容末尾；接受补全时会替换整个选区，不再与幽灵文本重叠。
- 修复点击补全时瞬时 Brigadier 解析状态导致的崩溃，以及聊天编辑器替换输入框后未立即取得键盘焦点的问题。
- 修复 Minecraft 1.21.4 与 26.2 中因纹理绘制参数顺序差异导致 Studio 图标被放大和裁切的问题。
- 补全候选、命令用法和快速文档会避让底部参数状态栏。
- 空间不足时，辅助面板会翻转到当前行上方。

## 客户端与服务端兼容

- 客户端和服务端模组版本允许不同。
- 每项网络功能独立协商。
- 不兼容或缺少的功能只会隐藏或禁用。
- 仅客户端和仅服务端安装仍然受到支持。
